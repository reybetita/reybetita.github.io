# Rey Noel Betita — Portfolio

A modern, responsive developer portfolio built with vanilla HTML, CSS, and JavaScript.

🌐 **Live:** [reybetita.github.io](https://reybetita.github.io)

## Features

- ✨ Dark glassmorphism design with vibrant accent colors
- 🎯 Animated particle background
- ⌨️ Typing animation hero
- 📱 Fully responsive (mobile-first)
- 🚀 Smooth scroll reveal animations
- 📊 Animated skill bars
- 📬 Contact form (mailto-based)

## Sections

- **Hero** — Introduction with typing effect
- **About** — Developer profile & stats
- **Projects** — Featured work showcase
- **Skills** — Tech stack & proficiency
- **Contact** — Reach out form & links

## Deployment

This site is hosted on **GitHub Pages** from the `main` branch.
